# 踩坑与解决实录

本文件保留公开仓库需要复用的工程经验，敏感环境信息与真实日志不在仓库保存。

## 版本隔离

### 现象

为 Chrome 152/153/154 新增的路径曾影响 Chrome 145，导致旧版本主页重复、下载横幅失效或配置串扰。

### 根因

不同 Chrome 大版本虽然功能相似，但混淆字段、消息模型和平台行为不同。把一个版本的解析结果或兜底通道共享给另一个版本，容易破坏旧语义。

### 规则

- 为 A 版本新增的解析或兜底默认只作用于 A 版本。
- 行为差异集中到版本特征/数据表。
- 旧版本已验证路径不因新版本自动适配而被复用。

## 主页重复打开

### 现象

冷启动或点击“+”后出现两个主页。

### 根因

同一个平台入口既承载 Chrome 内部新建标签，也承载用户主动新建标签。模块如果在平台已创建 NTP 后再主动创建主页，就会叠加两次导航。

### 规则

模块只做单向 URL 替换，让 Chrome 自己创建标签；不额外创建第二个主页。

## miuix 弹窗崩溃

### 现象

OverlayDialog 渲染点读取 NavigationEventDispatcherOwner 为空并崩溃。

### 根因

弹窗内容会被移动到 Scaffold 的 popup host 渲染，局部 CompositionLocalProvider 无法覆盖最终渲染点。

### 规则

在 Activity `setContent` 最外层提供根 NavigationEventDispatcherOwner，不把 provider 放在 Column 或弹窗调用点。

## 横幅拦截导致动画 NPE

### 现象

直接跳过 MessageContainer 入队后，Chrome 消息动画管理器读取空子项高度并崩溃。

### 规则

保留消息对象进入 Chrome 队列，仅隐藏目标 View 或在统一分发入口拦截，避免破坏平台状态机。

## 下载完成双 Toast

### 现象

同一下载先后显示“下载文件”和真实文件名。

### 根因

多个完成回调携带不同身份线索：一个入口只有 content URI，另一个入口稍后才提供真实文件名。立即用通用文案兜底会让两个事件生成不同去重键。

### 规则

- 不把 opaque content URI 当文件名。
- 身份未解析时先布防横幅拦截并延迟 Toast。
- 建立 URI 与真实文件名映射，跨回调归一身份。
- 不用 MIME 粗去重，避免连续不同下载被误合并。

## 文本脚本替换事故

### 现象

宽泛锚点把设置项插入错误卡片或漏掉字段定义。

### 规则

代码修改优先使用精确补丁；脚本替换必须限定唯一上下文，替换后读回文件核对目标片段。

## 大小写与混淆

### 现象

Windows 大小写不敏感掩盖文件名/类名不一致，Linux CI 或全新克隆后失败。

### 规则

新增 Java/Kotlin 文件后立即核对文件名大小写与类名；CI 使用 Linux 构建。
